# Opening Comics from Avrana
slug: open-comics
group: avrana-comics
host: read.avrana.net

## Phone or tablet
### Browser
store: none
url: none
1. Open Avrana from your Home Screen, or open https://avrana.net, and sign in. [UNVERIFIED on a real device]
2. On the Avrana home page, find the title under Recently added, or use Search. [UNVERIFIED on a real device]
3. Choose the title. Open takes you to its page, where you can start reading. [UNVERIFIED on a real device]
4. The page for that title opens on read.avrana.net. If a sign-in screen appears, sign in to Read there. It has its own sign-in for now. [UNVERIFIED on a real device]
5. To come back, use the Back button. If Avrana was opened from its Home Screen icon, the title may open in a separate browser view: close it to return to Avrana. [UNVERIFIED on a real device]

## If it does not open
### Try these in order
store: none
url: none
1. If a page says it cannot be found, go back to Avrana and open the title again. [UNVERIFIED on a real device]
2. Avrana opens titles in the browser, not in an app. To use an app instead, open the app and find the title there. [UNVERIFIED on a real device]
3. If read.avrana.net shows a sign-in screen again, your session there ended. Sign in, then open the title from Avrana again. [UNVERIFIED on a real device]
4. If Avrana says a library is unavailable, read the unavailable topic. [UNVERIFIED on a real device]
5. If it still fails, send a help request. [OWNER DECISION D-1: where to send a help request] [UNVERIFIED on a real device]

## Computer
### Browser
store: none
url: none
1. Open https://avrana.net and sign in. [UNVERIFIED on a real device]
2. Find the title under Recently added, or use Search, and choose it. [UNVERIFIED on a real device]
3. The page for that title opens in the same tab on read.avrana.net. Use the browser's Back button to return to Avrana. [UNVERIFIED on a real device]
