## Verification protocol (for every X row)

1. Fresh Opus agent, clean context; receives only: the defect text with reproduction, expected behaviour, the branch, and the implementer's test list.
2. Reproduces the defect on `2cb228f` (main checkout, read-only) with the original probe or test.
3. Runs the same against the fix branch; runs the implementer's tests and the neighbouring modules; reads the diff for scope creep, weakened security checks, changed assertions that merely match new output.
4. Verdict ACCEPT / REJECT with reasons; REJECT goes back to the implementer with the verifier's evidence.
