#   component | artifact (relative to the run directory) | restore destination | method

# a component added to the backup without a line here fails the restore test.

# Methods
#   copy        copy the file to the destination while the service is stopped
#   copy-as     same, but the file is RENAMED on the way back (the destination name differs)
#   untar       zstd -dc ARTIFACT | tar -C DESTINATION -xpf -
#   psql        zstd -dc ARTIFACT | docker exec -i <container> psql ...   (see BOOTSTRAP.md)
#   mariadb     zstd -dc ARTIFACT | docker exec -i <container> mariadb ... (see BOOTSTRAP.md)
