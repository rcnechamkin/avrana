# Comics and manga: how to read and which app to install

Address: https://read.avrana.net

In a browser, go to the address and choose the Avrana sign-in button.

## Which app to install

Comic reader apps connect through an OPDS catalog. The catalog address is
https://read.avrana.net/opds/v1.2/catalog and you sign in with your Avrana email address and password.

- iPhone and iPad: Panels from the App Store. Add a comic service with the catalog address.
- Android: Moon+ Reader or Librera, both from Google Play. Add a catalog with the catalog address.
- Any browser: https://read.avrana.net with the Avrana sign-in button.
