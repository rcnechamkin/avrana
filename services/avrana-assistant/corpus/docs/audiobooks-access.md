# Audiobooks: how to listen and which app to install

Address: https://listen.avrana.net

Audiobooks uses single sign-on, so there is no separate password: choose the Avrana sign-in option.

## Which app to install

- iPhone and iPad: AudioBooth (recommended) or Absorb, both from the App Store.
  - AudioBooth: add the server https://listen.avrana.net, choose SSO, then sign in with your Avrana account.
  - Absorb: add the server https://listen.avrana.net and choose the Avrana sign-in option.
- Android: Absorb (recommended) or Audiobookshelf, both from Google Play. Add the server
  https://listen.avrana.net and choose the Avrana sign-in option.
- Any browser: go to https://listen.avrana.net and choose the Avrana sign-in button.
