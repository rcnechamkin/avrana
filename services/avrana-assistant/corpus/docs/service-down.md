# A service seems down or is not working

This assistant cannot see whether a service is up or down. It does not have a live status source, so it
will not tell you that something is working, broken or fixed. Anything it said about live status would
be a guess.

## What you can try

- Try again after a minute, and try another device or app.
- Use an app where your service's help page recommends one; a web browser can be less reliable.
- Check your service's help page on your Avrana home page for the correct server address and sign-in
  steps.

## If it is still not working

Contact support and include which service (the web address) and what you saw. See "How to contact
support".
