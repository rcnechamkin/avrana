# How to ask for something that is missing

If something you want is not in a library you can use, you can ask for it.

- Open the Request tile on your Avrana home page (https://avrana.net). It opens a page listing what you
  can ask for with your account.
- The Request tile shows only the request options your account may use. If it is missing or does not
  list what you want, see "Why can't I see a library?".
- Search for the title in the request service for that library and make the request. It appears in the library once it
  has been added.

This assistant cannot file a request for you. It can only point you to the right place. How long a
request takes is not something the assistant can see.
